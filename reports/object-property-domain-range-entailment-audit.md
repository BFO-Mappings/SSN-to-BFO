# Object-Property Domain/Range Entailment Audit

## Scope

This report audits locally asserted object-property `rdfs:domain` and `rdfs:range` axioms in `SSN2BFO.ttl` under the refined entailment policy: remove a local domain or range only when the same typing remains entailed after that local axiom is removed. The mere existence of a `rdfs:subPropertyOf`, `owl:equivalentProperty`, or `owl:propertyChainAxiom` candidate is not treated as sufficient. Rejected or HermiT-unsafe mappings are not used as replacements.

This is report-only. It does not edit `SSN2BFO.ttl`, the workbook, imports, tools, examples, releases, generated artifacts, or existing reports.

Prior reports used as context:

- `reports/object-property-domain-range-fallback-policy-audit.md`
- `reports/deferred-candidate-domain-range-causality-retest.md`
- `reports/current-full-sosa-baseline-summary.md`

## Method

Every HermiT graph loaded the full local closure:

- `imports/cco.ttl`
- `imports/sosa.ttl`
- `imports/ssn.ttl`
- `imports/ssn-systems.ttl`
- a temporary `SSN2BFO.ttl` variant under `/tmp`

Each graph then removed all `owl:imports` triples and the established sample simplicity blockers:

- `sosa:isSampleOf rdf:type owl:FunctionalProperty`
- `sosa:hasSample rdf:type owl:InverseFunctionalProperty`

Reasoning command:

```bash
robot reason --reasoner HermiT --input <variant.ttl> --output <variant-reasoned.ttl>
```

Temporary output directory: `/tmp/ssn-to-bfo-domain-range-entailment-audit`.

Two probe contexts were used:

1. **Individual probe**: remove only the tested local domain or range triple, then add the probe class requested in the task.
2. **All-at-once probe**: remove all local `SSN2BFO.ttl` object-property domain/range triples, then add the same probe. This tests whether a blanket all-at-once removal preserves each intended typing entailment.

For properties with active `rdfs:subPropertyOf`, `owl:equivalentProperty`, or `owl:propertyChainAxiom` mappings, an additional individual follow-up removed the tested local axiom and the active mapping triples for that property. No mapping-removal follow-up was needed in the all-at-once context because no all-at-once probe remained unsatisfiable.
